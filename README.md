\# Operation Dashboard



An interactive PowerBI dashboard designed to monitor and analyze manufacturing operations. It provides a comprehensive overview of production volume, efficiency, customer satisfaction, and defect rates, allowing stakeholders to identify bottlenecks and optimize shift performance.

\## 📈 Key Insights \& Features

\- \*\*KPI Tracking:\*\* Monitors Average Efficiency (69.37), Customer Satisfaction (69.37), Defect Rate (2.78), and Average On-Time Delivery (92.42).

\- \*\*Production Analysis:\*\* Breaks down production volume by Category, Region (North, South, East, West, Central), Shift Type (Day, Rotational, Night), and Priority (Low, Medium, High, Critical).

\- \*\*Trend Analysis:\*\* Visualizes production volume against targets over a specified date range (01-01-2022 to 19-06-2024).

\- \*\*Interactive Filters:\*\* Includes dynamic slicers for Date, Category, Month, and Priority to drill down into specific operational areas.
